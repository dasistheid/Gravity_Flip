# Gravity Flip

Платформер на Pygame, написанный в рамках проекта по программной инженерии. Игрок бегает по платформам, прыгает на врагов, собирает монеты и кристаллы. Главная фишка — можно перевернуть гравитацию, чтобы бежать по потолку.

Вся графика нарисована кодом через `pygame.draw` — в проекте нет ни одного спрайта. Звёзды на фоне, свечение у объектов, частицы при прыжках и смерти — всё это тоже код.

## Что есть в игре

**Механика:**
- Движение влево-вправо, обычный и двойной прыжок
- Переворот гравитации на клавишу G — есть 3 заряда, восполняются кристаллами
- При перевороте персонаж начинает падать вверх
- Столкновения с платформами, включая движущиеся

**Враги (4 типа):**
- Обычные — ходят по платформе
- Прыгающие — периодически подпрыгивают
- Летающие — перемещаются по воздуху синусоидой
- Рывковые — ходят как обычные, но периодически делают резкий рывок
- Шипованные — на них нельзя запрыгнуть сверху, только обходить

**Предметы:**
- Монеты — дают очки
- Кристаллы — восполняют заряд гравитации
- Сердца — добавляют жизнь (если меньше максимума)

**Прочее:**
- Уровни генерируются случайно при каждом запуске и после каждой двери
- Комбо-множитель за сбор предметов подряд
- 3 жизни, при смерти респавн на ближайшей платформе
- При 0 жизней — экран Game Over со статистикой

## Как запустить

Нужен Python 3.8+ и Pygame.
